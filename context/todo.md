# Purpose

This document is the master implementation backlog for the AI Career Interview Platform.

It contains every planned task for the project, organized by milestone and
module.

Unlike `next-task.md`, which contains only the current highest-priority task,
this document contains the complete roadmap.

Tasks should move through the following lifecycle:

```
Backlog
    ↓
Planned
    ↓
In Progress
    ↓
Completed
```

Never delete completed tasks.
