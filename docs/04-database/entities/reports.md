# Purpose

The `reports` table stores the final interview report generated after all
questions have been evaluated.

A report represents the complete outcome of an interview session and provides
an actionable summary for the candidate.

It aggregates all question-level evaluations into interview-level insights.

---

# Responsibilities

The reports entity is responsible for:

- Overall interview score
- Category-wise scores
- Executive summary
- Strength identification
- Weakness identification
- Hiring recommendation
- Improvement roadmap
- Report generation metadata

It is **not** responsible for:

- Individual answer evaluations
- Question generation
- Resume parsing

# Business Rules

- Every completed interview generates exactly one report.
- Reports are immutable after generation.
- Report regeneration increments `report_version`.
- Category scores are derived from evaluations.
- Hiring recommendation must be consistent with overall score and evaluation outcomes.

# Security Considerations

Reports contain candidate assessment data.

Requirements:

- Accessible only to interview owner and authorized administrators.
- PDF downloads require authenticated access.
- Internal evaluation metadata must not be exposed.
- Report storage should support encryption at rest.

# SQL Example

```sql
CREATE TABLE reports (
    id UUID PRIMARY KEY,
    interview_id UUID UNIQUE NOT NULL REFERENCES interviews(id),
    overall_score DECIMAL(5,2) NOT NULL,
    technical_score DECIMAL(5,2),
    communication_score DECIMAL(5,2),
    problem_solving_score DECIMAL(5,2),
    executive_summary TEXT NOT NULL,
    strengths JSONB NOT NULL,
    weaknesses JSONB NOT NULL,
    improvement_roadmap JSONB NOT NULL,
    hiring_recommendation VARCHAR(30) NOT NULL,
    report_version INTEGER NOT NULL DEFAULT 1,
    report_model VARCHAR(50) NOT NULL,
    pdf_generated BOOLEAN NOT NULL DEFAULT FALSE,
    pdf_storage_path TEXT,
    generated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

# SQLAlchemy Example

```python
class Report(Base):
    __tablename__ = "reports"

    id = mapped_column(UUID(as_uuid=True), primary_key=True)

    interview_id = mapped_column(
        UUID(as_uuid=True),
        ForeignKey("interviews.id"),
        unique=True,
        nullable=False
    )

    overall_score = mapped_column(Numeric(5, 2), nullable=False)

    technical_score = mapped_column(Numeric(5, 2))

    communication_score = mapped_column(Numeric(5, 2))

    problem_solving_score = mapped_column(Numeric(5, 2))

    executive_summary = mapped_column(Text, nullable=False)

    strengths = mapped_column(JSONB)

    weaknesses = mapped_column(JSONB)

    improvement_roadmap = mapped_column(JSONB)

    hiring_recommendation = mapped_column(String(30), nullable=False)

    report_version = mapped_column(Integer, default=1)

    report_model = mapped_column(String(50), nullable=False)

    pdf_generated = mapped_column(Boolean, default=False)

    pdf_storage_path = mapped_column(Text)

    generated_at = mapped_column(DateTime(timezone=True))

    created_at = mapped_column(DateTime(timezone=True))

    updated_at = mapped_column(DateTime(timezone=True))
```
