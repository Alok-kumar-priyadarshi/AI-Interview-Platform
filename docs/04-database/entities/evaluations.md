# Purpose

The `evaluations` table stores the AI-generated assessment for every submitted
interview answer.

Each evaluation is generated after the AI analyzes the candidate's response
against the expected answer characteristics and evaluation rubric.

This entity provides structured feedback that powers interview reports,
analytics, and candidate improvement recommendations.

---

# Responsibilities

The evaluations entity is responsible for:

- AI scoring
- Technical assessment
- Communication assessment
- Problem-solving assessment
- Confidence analysis
- Strength identification
- Weakness identification
- Improvement recommendations
- Evaluation metadata

It is **not** responsible for:

- Question generation
- Candidate responses
- Final interview aggregation

# Column Definitions

## overall_score

Final weighted score.

Range:

```
0.00

↓

100.00
```

---

## technical_score

Measures technical correctness.

Factors:

- Accuracy
- Completeness
- Correct terminology
- Depth

---

## communication_score

Measures communication quality.

Factors:

- Clarity
- Structure
- Conciseness
- Explanation quality

---

## problem_solving_score

Measures analytical ability.

Factors:

- Reasoning
- Trade-offs
- Approach
- Decision making

---

## confidence_score

Measures AI confidence in the evaluation.

Not the candidate's confidence.

---

## strengths

Structured list of positive observations.

Example:

```json
[
  "Strong understanding of indexing",
  "Good explanation structure"
]
```

---

## weaknesses

Structured list of improvement areas.

Example:

```json
[
  "Missed edge cases",
  "Limited discussion of scalability"
]
```

---

## improvement_suggestions

Actionable recommendations.

Example:

```json
[
  "Study transaction isolation levels",
  "Practice explaining trade-offs"
]
```

---

## detailed_feedback

Natural-language explanation generated by the AI.

May contain multiple paragraphs.

---

## evaluation_model

AI model used.

Example:

```
groq-llama-4
```

---

## evaluation_prompt_version

Prompt template version.

Supports reproducibility.

---

## evaluation_duration_ms

Time required to generate the evaluation.

Useful for monitoring latency.

---

## created_at

Evaluation creation timestamp.

---

## updated_at

Updated only if the evaluation is regenerated.

# Business Rules

- Every submitted answer produces one evaluation.
- Evaluations are immutable after generation.
- Regeneration creates a new evaluation version in future releases.
- Scores must remain internally consistent with the rubric.
- Improvement suggestions should always accompany weaknesses.

# Security Considerations

Evaluation data influences candidate decisions.

Requirements:

- Do not expose internal prompts.
- Do not expose reasoning traces.
- Prevent unauthorized modification.
- Log evaluation regeneration events.
- Restrict access to interview owners and administrators.

# SQL Example

```sql
CREATE TABLE evaluations (
    id UUID PRIMARY KEY,
    answer_id UUID UNIQUE NOT NULL REFERENCES interview_answers(id),
    overall_score DECIMAL(5,2) NOT NULL,
    technical_score DECIMAL(5,2),
    communication_score DECIMAL(5,2),
    problem_solving_score DECIMAL(5,2),
    confidence_score DECIMAL(5,2),
    strengths JSONB NOT NULL,
    weaknesses JSONB NOT NULL,
    improvement_suggestions JSONB NOT NULL,
    detailed_feedback TEXT,
    evaluation_model VARCHAR(50) NOT NULL,
    evaluation_prompt_version VARCHAR(30),
    evaluation_duration_ms INTEGER,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

# SQLAlchemy Example

```python
class Evaluation(Base):

    problem_solving_score = mapped_column(Numeric(5, 2))

    confidence_score = mapped_column(Numeric(5, 2))

    strengths = mapped_column(JSONB)

    weaknesses = mapped_column(JSONB)

    improvement_suggestions = mapped_column(JSONB)

    detailed_feedback = mapped_column(Text)

    evaluation_model = mapped_column(String(50), nullable=False)

    evaluation_prompt_version = mapped_column(String(30))

    evaluation_duration_ms = mapped_column(Integer)

    created_at = mapped_column(DateTime(timezone=True))

    updated_at = mapped_column(DateTime(timezone=True))
```
