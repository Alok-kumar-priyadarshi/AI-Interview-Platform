# Purpose

The `interview_questions` table stores every question generated for an
interview session.

Each question is generated by the AI Interview Engine based on:

- Candidate profile
- Resume
- Target role
- Experience level
- Difficulty
- Interview type

Questions are immutable after generation.

---

# Responsibilities

The interview_questions entity is responsible for:

- Question content
- Question ordering
- Question category
- Difficulty
- Evaluation criteria
- AI generation metadata
- Expected answer characteristics

It is **not** responsible for:

- Candidate answers
- Final evaluation
- Interview summary

# Column Definitions

## question_number

Display order within an interview.

Example:

```
1

2

3

...

10
```

Must be unique within an interview.

---

## category

Question classification.

Allowed values:

```
technical

behavioral

hr

system_design

coding

database

oop

operating_system

networking

aptitude

custom
```

Future categories may be added without schema changes.

---

## difficulty

Allowed values:

```
easy

medium

hard
```

Independent of interview-level difficulty.

---

## question_text

The complete question presented to the candidate.

Examples:

```
Explain ACID properties.

Design a URL shortener.

What is dependency injection?
```

---

## expected_answer_points

Structured outline of concepts expected in a good answer.

Example:

```json
[
  "Definition",
  "Advantages",
  "Real-world example",
  "Trade-offs"
]
```

Used internally by the evaluation engine.

---

## evaluation_rubric

Detailed scoring criteria.

Example:

```json
{
  "technical_accuracy": 40,
  "communication": 20,
  "depth": 20,
  "examples": 20
}
```

The weights should total 100.

---

## estimated_time_seconds

Suggested answering time.

Examples:

```
60

120

300
```

---

## ai_model

Model used for question generation.

Example:

```
groq-llama-4
```

---

## generation_prompt_version

Version identifier of the prompt template used.

Example:

```
v1.2

v2.0
```

Supports prompt version tracking and reproducibility.

---

## created_at

Timestamp when the question was generated.

# Business Rules

- Questions belong to exactly one interview.
- Question order cannot change after generation.
- Question text is immutable.
- Evaluation rubric is immutable.
- Duplicate question numbers within an interview are prohibited.

# Validation Rules

Question Text

- Required
- Maximum 10,000 characters

Question Number

- Positive integer
- Unique per interview

Estimated Time

- Greater than 0
- Optional

Rubric

- Valid JSON
- Total score weight = 100

---

# Security Considerations

Questions must not expose:

- Internal prompts
- Hidden evaluation logic
- System instructions
- AI reasoning traces

Only the candidate-facing question should be returned to clients.

# SQL Example

```sql
CREATE TABLE interview_questions (
    id UUID PRIMARY KEY,
    interview_id UUID NOT NULL REFERENCES interviews(id),
    question_number INTEGER NOT NULL,
    category VARCHAR(40) NOT NULL,
    difficulty VARCHAR(20) NOT NULL,
    question_text TEXT NOT NULL,
    expected_answer_points JSONB NOT NULL,
    evaluation_rubric JSONB NOT NULL,
    estimated_time_seconds INTEGER,
    ai_model VARCHAR(50) NOT NULL,
    generation_prompt_version VARCHAR(30),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_questions_interview_order
        UNIQUE (interview_id, question_number)
);
```

# SQLAlchemy Example

```python
class InterviewQuestion(Base):
    __tablename__ = "interview_questions"

    id = mapped_column(UUID(as_uuid=True), primary_key=True)

    interview_id = mapped_column(
        UUID(as_uuid=True),
        ForeignKey("interviews.id"),
        nullable=False
    )

    question_number = mapped_column(Integer, nullable=False)

    category = mapped_column(String(40), nullable=False)

    difficulty = mapped_column(String(20), default="medium")

    question_text = mapped_column(Text, nullable=False)

    expected_answer_points = mapped_column(JSONB)

    evaluation_rubric = mapped_column(JSONB)

    estimated_time_seconds = mapped_column(Integer)

    ai_model = mapped_column(String(50), nullable=False)

    generation_prompt_version = mapped_column(String(30))

    created_at = mapped_column(DateTime(timezone=True))
```
