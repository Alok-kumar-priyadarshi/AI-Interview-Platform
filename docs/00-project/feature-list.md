# Purpose

This document is the single source of truth for every feature in the project.

Every feature receives a unique Feature ID (FR-XXX). These IDs must be referenced in:
- Requirements
- API Contracts
- Database Design
- Frontend
- Backend
- Mermaid Diagrams
- Test Cases
- Context Files
